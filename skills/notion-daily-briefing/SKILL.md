# Notion 일일 이메일 브리핑 루틴

## 실행 조건
- **대한민국 공휴일 및 주말(토·일) 실행 금지**
- 평일(월~금)에만 자동 실행

---

## STEP 1 — Gmail 조회

**조회 범위 (한국 시간 KST 기준)**
- 화~금요일: 어제 오전 00:00 ~ 오늘 현재
- 월요일: 지난 금요일 오전 00:00 ~ 오늘 현재
- 조회 상한: 최신순 최대 30건

**포함 기준**
- 읽지 않은 메일: 전체 포함
- 읽은 메일: 발신자가 사내 인원이거나 제목에 `긴급` / `확인` / `회신` 포함된 것만
- 제외: 뉴스레터, 자동알림, no-reply 발신자 시스템 메일
- 참고: 해당 Gmail은 Armaranth10 POP3 계정으로 읽음 처리가 미반영될 수 있으므로, 읽음 상태를 보수적으로 해석하여 반영

---

## STEP 2 — 우선순위 분류

| 등급 | 기준 | 조치 형식 |
|------|------|-----------|
| 🔴 P1 즉시처리 | 오늘 기한 또는 긴급 / 수신자에 한이현(han@solardin.com) 직접 포함 / 발신: 기구설계팀(김영철·정예진·홍대영) 또는 시스템설계팀 | 원인 + 구체적 조치사항 명시 |
| 🟠 P2 오늘 중 처리 | 2~3일 내 기한, 의사결정 필요 | 원인 + 구체적 조치사항 명시 |
| 🟡 P3 이번주 처리 | 7일 내 기한, 정보공유 | 요약 1줄 |
| 🟢 P4 보관참조 | 기한 없음, 공지·알림 | 요약 1줄 |

**요약 규칙**
- 반복 메일(일일회의록, 연속 회신)은 최신 1건만 요약
- 각 항목에 회신 기한 `D-숫자` 명시
- P1·P2는 `원인: ○○ / 조치: ○○` 형식으로 2줄 이내 작성

## STEP 4 — Notion 브리핑 페이지 작성

### 페이지 제목
```
이메일 브리핑 - YYYY.MM.DD (요일)
```
예시: `이메일 브리핑 - 2026.05.19 (화)`

요일 표기: 월·화·수·목·금
