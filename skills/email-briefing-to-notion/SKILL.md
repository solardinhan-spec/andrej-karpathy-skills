# Email Briefing

## 사전 확인

오늘 날짜(KST)를 확인한다.  
**사용자가 날짜를 직접 명시한 경우 해당 날짜를 우선 사용한다.**  
(`currentDate` 시스템 값은 세션 시작 시점에 고정되므로 신뢰하지 않는다.)

대한민국 공휴일 또는 주말(토·일)이면 **즉시 종료**한다.  
평일이면 아래 STEP 1~4를 순서대로 실행한다.

---

## STEP 1 — Gmail 조회 (1회 호출)

**조회 범위 (KST 기준) — 직전 영업일 기준으로 판단**

| 오늘 | 조회 시작 |
|------|-----------|
| 화~금 (직전 영업일 = 어제) | 어제 오전 00:00 |
| 월요일 | 지난 금요일 오전 00:00 |
| 연휴 직후 첫 평일 | 직전 영업일(공휴일·주말 제외) 오전 00:00 |

조회 종료 시점은 항상 현재.

**포함 조건**
- 읽지 않은 메일: 전체 포함
- 읽은 메일: 발신자가 사내 인원(`@solardin.com` 도메인)이거나 제목에 "긴급" / "확인" / "회신" 포함된 것만

**제외 조건**
- `no-reply`, `noreply` 발신자, 뉴스레터, 자동알림
- 시스템 메일(`_sysmaster_@solardin.com`): 수신자에 한이현(`han@solardin.com`)이 직접 포함된 경우만 **P3**로 포함, 그 외 제외
- 제목 필터: `-subject:(특이사항 없음)`

**상한**: 최신순 15건

> ⚠️ 이 Gmail은 Armaranth10 POP3 계정으로 읽음 상태가 미반영될 수 있으므로 보수적으로 처리한다.

## STEP 2 — 우선순위 분류

아래 조건은 **OR 관계**다. 하나라도 해당하면 해당 등급으로 분류하며, 상위 등급 조건에 먼저 해당하면 하위 등급으로 내리지 않는다.

### 🔴 P1 즉시처리 (오늘 기한 또는 긴급)
다음 중 하나 이상 해당:
- 수신자에 한이현(`han@solardin.com`) 직접 포함 **AND** 사람이 발신(시스템 메일 제외)
- 발신자가 기구설계팀(김영철 `yckim`·정예진 `yjjung`·홍대영 `dyhong`) 또는 시스템설계팀
- 제목 또는 본문에 "긴급" 포함 **AND** 설계 반영 필요사항

### 🟠 P2 오늘 중 처리 (2~3일 내 기한, 의사결정 필요)
P1 미해당이나 다음에 해당:
- 승인 요청, 현장 이슈 모니터링, 기한이 명시된 확인 요청

### 🟡 P3 이번주 처리 (7일 내 기한, 정보공유)
- 시스템 메일 중 한이현 직접 수신분 포함

### 🟢 P4 보관참조 (기한 없음, 공지·알림)

**공통 규칙**
- 반복 메일(일일업무보고, 연속 회신)은 최신 1건만 요약
- Gmail 검색 결과 스니펫을 참고하여 전날 브리핑과 중복되는 항목은 `(중복)` 표시
- 기한이 명시된 경우 `D-숫자` 표기, 미명시 시 `D-?` 표기
- (영업팀) 일일 업무 보고 이상 없으면 P4 테이블에 1줄로만 요약

## STEP 4 — Notion 페이지 작성 (1회 호출)

이메일 브리핑 부모 페이지(ID: `3643e986-a942-812e-b4e9-dca08f857e86`) 하위에 새 페이지를 생성한다.

**페이지 제목**: `YYYY.MM.DD (요일)` 형식 (예: `2026.05.26 (화)`)  
**페이지 아이콘**: 📬

### 본문 구성 (순서 고정)

1. **요약 헤더**: `🔴 P1 (N건) → 🟠 P2 (N건) → 🟡 P3 (N건) → 🟢 P4 (N건)`
2. **P1 섹션**: 건별로 메타정보(발신·수신·일시) + 이슈 테이블(이슈 / 장비·건 / 현황 / 상태) + 액션 아이템(체크리스트)
3. **P2 섹션**: 건별로 메타정보 + 원인/조치 한 줄 + 액션 아이템
4. **P3 섹션**: 테이블 1개 (발신자 | 제목 | D-day | 요약)
5. **P4 섹션**: 테이블 1개 (발신자 | 제목 | 요약)
6. **캘린더 섹션**: 테이블 1개 (날짜/시간 | 일정명 | P1·P2 연관)
7. **푸터**: `@한이현 🤖 자동 작성 by Claude Code`

**제약사항**
- 캘린더 이벤트 생성 **금지**
- Gmail Draft 작성 **금지**
- 도구 호출: Gmail 1회 · Calendar 1회 · Notion 1회
