## 시스템 핵심 개요

### 해결 과제
반도체 장비 설계 환경에서 발생하는 문제:
- 도면 버전 혼재 → 구형 도면으로 부품 제작 사고
- BOM 수기 관리 → 변경 이력 추적 불가
- 승인 프로세스 불투명 → 미승인 도면 유출
- 분산된 파일 관리 → 중복 설계, 재작업 낭비

### 핵심 해결 방향

```
[설계자 CAD 작업]
       ↓
[도면 업로드 (PDF + STEP)]
       ↓
[자동 채번 + Revision 관리]
       ↓
[승인 워크플로우 (In Work → Released)]
       ↓
[BOM 연계 + 전 부서 알림]
       ↓
[Cloud Storage 영구 보관]
```

### 기술 스택 요약

| 레이어 | 기술 | 역할 |
|--------|------|------|
| Frontend | Next.js 14 + Tailwind CSS | 대시보드, BOM 뷰어, 승인 UI |
| Backend | Node.js + Express | REST API, 비즈니스 로직 |
| Database | Firestore (NoSQL) | Part/도면/BOM 메타데이터 |
| Storage | Cloud Storage | PDF 도면, STEP/CAD 파일 |
| Auth | Firebase Authentication | 역할 기반 접근 제어 |
| Functions | Cloud Functions v2 | 이벤트 트리거, 자동화 |
| Deploy | Cloud Run | 서버리스 컨테이너 배포 |
| IaC | Terraform | 인프라 코드화 |
| CI/CD | Cloud Build + GitHub Actions | 자동 빌드/배포 |
| AI | Claude Code (Anthropic API) | 설계 지원, 코드 생성 |
