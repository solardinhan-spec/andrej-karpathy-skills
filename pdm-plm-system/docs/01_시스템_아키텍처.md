## 1.2 데이터 모델 설계

### Firestore 컬렉션 구조

```
firestore/
├── sequences/                    # 자동 채번 카운터
│   ├── CH → { currentSeq: 42 }  # Chiller
│   ├── WC → { currentSeq: 15 }  # Wafer Chuck
│   └── AS → { currentSeq: 7 }   # Assembly
│
├── parts/                        # 품목 마스터
│   └── CH-001/
│       ├── partNo: "CH-001"
│       ├── name: "냉각수 배관 어셈블리"
│       ├── revision: "C"
│       ├── material: "SUS316L"
│       ├── weight: 2.4
│       ├── status: "Released"    # In Work | Released | Obsolete
│       ├── createdBy: "uid_xxx"
│       └── createdAt: timestamp
│
├── drawings/                     # 도면 이력 (Immutable - 삭제 불가)
│   ├── CH-001-A/
│   │   ├── partNo: "CH-001"
│   │   ├── revision: "A"
│   │   ├── fileUrl: "gs://..."
│   │   ├── cadFile: "gs://..."
│   │   ├── status: "Obsolete"
│   │   ├── uploadedAt: timestamp
│   │   ├── approvedBy: "uid_mgr"
│   │   └── approvedDate: timestamp
│   ├── CH-001-B/ → { status: "Obsolete" }
│   └── CH-001-C/ → { status: "Released" }
│
├── bom/                          # BOM 구조 (상위-하위 관계)
│   └── CH-001-BOM/
│       ├── parent: "CH-001"
│       ├── revision: "C"
│       └── children: [
│           ├── { partNo: "CH-010", qty: 2, unit: "EA" }
│           ├── { partNo: "CH-011", qty: 4, unit: "EA" }
│           └── { partNo: "CH-012", qty: 1, unit: "SET" }
│           ]
│
├── ecn/                          # ECN (Engineering Change Notice)
│   └── ECN-2024-001/
│       ├── ecnNo: "ECN-2024-001"
│       ├── affectedParts: ["CH-001", "CH-010"]
│       ├── changeReason: "재질 변경 SUS304 → SUS316L"
│       ├── requestedBy: "uid_eng"
│       └── status: "Approved"
│
└── users/                        # 사용자 프로필 + 권한
    └── uid_xxx/
        ├── name: "홍길동"
        ├── email: "hong@company.com"
        ├── department: "기계설계팀"
        └── role: "designer"      # admin | designer | reviewer | viewer
```

## 1.3 Part 상태 전이도 (State Machine)

```
        [신규 등록]
             │
             ▼
        ┌─────────┐
        │ In Work │◄──────────────────┐
        └────┬────┘                   │
             │ 설계자 업로드 완료        │ ECO/ECN 발행
             ▼                        │ (변경 시작)
        ┌─────────┐                   │
        │ In Review│                  │
        └────┬────┘                   │
             │ 검토자 확인              │
             ▼                        │
        ┌─────────┐                   │
        │Released │──────────────────►┘
        └────┬────┘
             │ 신규 Rev 배포 시
             ▼
        ┌──────────┐
        │ Obsolete │ (영구 보존, 조회만 가능)
        └──────────┘
```

## 1.4 Revision 채번 규칙

| 단계 | 리비전 | 설명 |
|------|--------|------|
| 초기 설계 | A | 최초 등록 |
| 1차 변경 | B | 마이너 수정 |
| ... | ... | |
| 26차 변경 | Z | |
| 27차 변경 | AA | 알파벳 조합 확장 |
| ... | AB, AC... | |

> **반도체 장비 특성 반영:** 도면 번호 Prefix는 장비 분류 코드로 관리  
> `CH` = Chiller, `WC` = Wafer Chuck, `AS` = Assembly, `EL` = Electrical
